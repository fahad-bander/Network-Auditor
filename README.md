# Network Auditor

A Python-based network security auditing tool for authorized network assessments.

## Features

- ARP host discovery
- TCP port scanning
- Service and banner detection
- HTTP security-header checks
- TLS analysis
- Security findings
- JSON reporting
- Bounded asynchronous scanning

## Installation

```bash
git clone https://github.com/fahad-bander/Network-Auditor.git
cd Network-Auditor
pip install -r requirements.txt
