\# Network Auditor



A low-impact network security auditing tool written in Python.



\## Features



\- IPv4 network discovery

\- TCP service scanning

\- Service banner detection

\- HTTP security header inspection

\- Basic security findings with severity levels

\- JSON report generation

\- Bounded concurrent scanning



\## Requirements



\- Python 3.11+

\- Npcap on Windows

\- Required Python packages:

pip install -r requirements.txt
